# History

Shipped plans and superseded research, kept for provenance. These do
NOT describe current behavior — living decisions live in `docs/adr/`,
and where a plan's decision was later revised (e.g. the branch-first
revision of adr/0003 reversing auto merge-back), the plan carries a
banner saying so.

- `PLAN-*.md` — implementation plans for shipped releases/features.
- `COMPUTER-VISION-RESEARCH.md`, `testing-enhancements-research.md` —
  research reports that fed shipped features; cite-checked at the time
  they were written, not maintained since.

## Superseded isolation plans

`PLAN-branch-worktree-visibility.md` describes the per-chat worktree

0012–0016), removed for good by ADR-0017. Kept for provenance only —

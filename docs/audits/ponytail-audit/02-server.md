## Out-of-scope observation (not counted)

`get_db()` re-runs the whole migration chain + `migrate_workspaces` (executescript, 6 PRAGMA table_info, an UPDATE, a GROUP BY) on every API call; the once-per-process flags mask the worst of it. A run-once-per-process guard would be both faster and simpler — behavior-affecting perf, so left uncounted per the scope rules.
